# DocAI RAG

A full-stack AI-powered PDF Question Answering application using Retrieval-Augmented Generation (RAG).

## 🚀 Features

- 📄 Upload PDF documents
- 🔍 Extract and process document content
- ✂️ Split documents into chunks
- 🧠 Generate embeddings
- 🔎 Retrieve relevant document context
- 🤖 Generate answers using an LLM
- 💻 React-based frontend
- ⚡ Python backend API
- 🔐 Environment variables for API keys

## 🛠️ Tech Stack

### Frontend
- React.js
- Vite
- JavaScript
- CSS

### Backend
- Python
- FastAPI
- RAG
- LangChain
- Vector Search
- LLM
